开源大模型技术演进综述

从 2017 年的初代 Transformer 到 2026 年的 DeepSeek-V4、GLM-5 与 Kimi K3，按时间线索梳理开源大模型的关键算法与技术脉络。

更新 2026-10-30记录 2026-10-30

引言

这篇综述以时间为线索，串联大模型技术演进的几个关键节点：Transformer 架构的确立（2017）、预训练范式与对齐技术（2018–2022）、开源模型与本地部署生态（2023，以 LLaMA 与 Ollama 为代表）、国产开源模型的爆发（2023–2025，以 DeepSeek、GLM、Qwen 为代表），以及开源模型对闭源前沿的全面追赶与反超（2025 末–2026，以 DeepSeek-V4、GLM-5、Kimi K3 为代表）。每个节点对应的不只是模型的发布，更是一批至今仍在沿用的核心算法：注意力机制、MoE、MLA、GRPO、多 Token 预测、稀疏/线性注意力、Muon 优化器等。文末附完整时间线表和技术主线小结。

起点：Transformer（2017）

2017 年 6 月，Google 团队发表论文《Attention Is All You Need》（Vaswani et al., NeurIPS 2017），提出 Transformer 架构，彻底抛弃了 RNN 的循环结构和 CNN 的卷积结构，仅依赖注意力机制建模序列中的依赖关系。这是整个大模型时代的起点。

核心组件

  • 自注意力（Self-Attention）：每个 token 通过查询（Q）、键（K）、值（V）三组投影与其他所有 token 交互，计算复杂度为 O(n²·d)，但可以完全并行，解决了 RNN 无法并行训练的根本瓶颈。
  • 多头注意力（Multi-Head Attention）：将注意力拆分为多个头，各自在不同的表示子空间中学习不同类型的依赖关系（句法、指代、位置等）。
  • 位置编码：原始论文使用固定的正弦/余弦位置编码；后来的模型普遍改用旋转位置编码 RoPE（RoFormer，2021），通过旋转向量把相对位置信息注入注意力计算，成为 LLaMA 系之后几乎所有开源模型的标配。
  • 前馈网络（FFN）：两层全连接网络配合非线性激活；现代模型普遍采用 SwiGLU 门控激活替代 ReLU。
  • 残差连接与层归一化：保障深层网络可训练；现代模型把 LayerNorm 换成更稳定的 RMSNorm，并采用 Pre-Norm 布局。

原始 Transformer 是编码器-解码器结构，随后分化出三条路线：仅编码器（BERT，理解任务）、仅解码器（GPT，生成任务）、编码器-解码器（T5）。最终仅解码器（decoder-only）路线胜出，成为今天所有主流大语言模型的骨架。

预训练范式与对齐技术（2018–2022）

从 GPT 到 GPT-3：规模即能力

  • GPT-1（2018-06，OpenAI）：确立"生成式预训练 + 下游微调"的两阶段范式。
  • BERT（2018-10，Google）：双向掩码语言模型，在理解类任务上横扫榜单，带动了第一波预训练研究热潮。
  • GPT-2（2019-02）：提出语言模型可作为"无监督多任务学习器"，zero-shot 能力初现。
  • GPT-3（2020-05）：1750 亿参数，验证了上下文学习（In-Context Learning）和少样本能力的涌现，从此"大力出奇迹"成为行业共识。

Scaling Laws：给烧钱提供理论依据

Kaplan et al.（2020-01）发现模型性能随参数量、数据量、计算量呈幂律提升，为扩大规模提供了量化预测工具。Chinchilla（2022-03，DeepMind）修正了结论：在给定算力预算下，参数量与训练数据量应等比例放大（约每参数 20 token），纠正了此前"模型过大、数据过少"的普遍做法。这两份工作是所有后续模型训练规模决策的基础。

RLHF 与 ChatGPT：对齐决定产品形态

InstructGPT（2022-01/03，OpenAI）提出经典的三阶段对齐流程：监督微调（SFT）→ 训练奖励模型（RM）→ 用 PPO 强化学习优化策略（RLHF）。ChatGPT（2022-11-30）把这套流程用在 GPT-3.5 上，以对话产品形态引爆全球，也宣告"预训练模型 + 对齐"成为大模型落地的标准管线。同期（2021-06），微软提出的 LoRA 证明了可以用低秩矩阵近似微调增量、冻结主干权重，成为参数高效微调（PEFT）事实上的标准，也是开源社区生态繁荣的关键技术之一。

开源化与本地部署：2023，LLaMA 与 Ollama

LLaMA：开源大模型的引爆点

2023 年 2 月，Meta 发布 LLaMA（7B–65B），用更小的参数量（配合 Chinchilla 最优数据配比）达到接近 GPT-3 的性能，并在泄漏后催生了整个开源微调生态。同年 7 月的 LLaMA 2 允许商用，进一步确立开源路线。LLaMA 确立了此后开源模型的标准配方：

  • decoder-only + RoPE 旋转位置编码；
  • RMSNorm（Pre-Norm）；
  • SwiGLU 激活的 FFN；
  • 分组查询注意力 GQA（LLaMA 2 70B 起采用，由多查询注意力 MQA 演化而来），大幅压缩 KV Cache，改善推理显存与吞吐。

同期还有 Mistral 7B（2023-09，滑动窗口注意力 SWA）和 Mixtral 8×7B（2023-12，把 MoE 带入开源领域），以及阿里 Qwen-7B（2023-08）、智谱 ChatGLM-6B（2023-03）等国产开源模型的第一波发布。

llama.cpp 与 Ollama：让大模型跑在个人电脑上

Georgi Gerganov 的 llama.cpp（2023-03）用纯 C/C++ 实现推理，配合 GGUF 量化格式（4-bit、5-bit 等低比特权重量化，源自 GGML 项目），让消费级 CPU/显卡也能运行大模型。Ollama（2023-07 开源）在 llama.cpp 之上封装了模型管理、CLI 和本地 API 服务，一条 ollama run 命令即可拉起模型，成为个人与大模型交互的入口级工具。Ollama 本身没有提出新算法，其意义在于把量化（quantization）、KV Cache 管理、内存映射加载这些推理工程打包成开箱即用的体验，是"开源权重 + 本地推理"生态成熟标志。

DeepSeek（2023–2025）：从跟随到引领

DeepSeek（深度求索）是这条时间线上算法密度最高的团队，其每一代模型几乎都对应一项被广泛引用的架构或训练创新。

DeepSeek LLM 与 DeepSeekMoE（2023–2024 初）

  • DeepSeek LLM 7B/67B（2023-11）：首个通用模型，验证了数据配比与训练稳定性方法论。
  • DeepSeekMoE（2024-01，论文 2024-01，用于 V2 及之后）：对 MoE 做两项改造——细粒度专家（把每个专家切得更小、开更多专家，提升组合表达能力）与共享专家隔离（一部分专家常驻处理通用知识，其余路由专家专注细分模式）。这一设计被后续众多开源 MoE 模型借鉴。

DeepSeek-V2：MLA 压缩 KV Cache（2024-05）

多头潜在注意力（Multi-head Latent Attention, MLA）把 KV 压缩到低维潜在向量，推理时只需缓存压缩后的潜向量，KV Cache 相比 MHA 缩小一个数量级，同时保持接近 MHA 的效果。这是 MoE（省激活参数算力）与 MLA（省推理显存）的组合拳，使 236B 总参 / 21B 激活的模型可以低成本推理，API 价格打到当时的白菜价。

DeepSeek-V3：极致工程化的稀疏大模型（2024-12）

  • 无辅助损失的负载均衡（Auxiliary-Loss-Free Balancing）：用动态偏置调整专家负载，避免传统辅助损失对主任务性能的干扰。
  • 多 Token 预测（Multi-Token Prediction, MTP）：训练时同时预测多个未来 token，提升数据效率并可为推理加速做投机解码。
  • FP8 混合精度训练：在超大规模上首次验证低精度训练的可行性，671B 总参 / 37B 激活的模型仅用约 278.8 万 H800 GPU 小时（约 557 万美元当量）完成预训练，改写了行业对训练成本与算力封锁的认知。

DeepSeek-R1：强化学习涌现推理能力（2025-01）

R1-Zero 证明了不依赖监督微调冷启动、纯强化学习（GRPO）也能涌现长链推理：模型在解数学/代码题时自发学会反思、验证和"顿悟时刻（aha moment）"，思维链长度随训练自然增长。

  • GRPO（Group Relative Policy Optimization）：最早在 DeepSeekMath（2024-02）中提出，去掉 PPO 的价值网络，用同一问题上采样一组回答的组内相对奖励作为基线，大幅降低 RL 训练成本，成为开源社区做 RL 最常用的算法。
  • R1 在 RL 之前加入少量冷启动数据、之后经历多阶段 RL + SFT 迭代，兼顾推理能力与可读性。
  • 蒸馏：把 R1 的推理轨迹蒸馏到 Qwen/Llama 小模型上，证明大模型推理能力可以迁移，小模型也能获得强推理表现。
  • 后续的 V3.1 / V3.2-Exp（2025-08/09）引入混合推理模式与稀疏注意力（DSA，DeepSeek Sparse Attention），把长上下文注意力计算复杂度进一步压低；V3.2 正式版（2025-12-02）在智能体工具评测中超越了 Kimi K2 Thinking，延续极致性价比路线。

DeepSeek-V4 与 V4.1（2026）：混合注意力与百万上下文成为默认

DeepSeek-V4（2026-04-24，MIT 许可）保留了 DeepSeekMoE 框架与 MTP 策略，架构上有三项关键创新：

  • 混合注意力架构：交替堆叠压缩稀疏注意力（CSA）——沿序列维度压缩 KV Cache 并结合 DSA——与深度压缩注意力（HCA）——以更大压缩率深度压缩但仍保持密集注意力。1M 上下文下每 token 计算量仅为 V3.2 的约 27%，KV Cache 约为其 10%。
  • 流形约束超连接（mHC）：把残差连接的映射约束到双随机矩阵流形（Birkhoff 多面体）上，增强深层网络层间信号传播的稳定性。
  • Muon 优化器：作为主优化器加速收敛、提升训练稳定性——Muon 系优化器自此成为 2026 年大模型训练的标配之一。

V4-Pro 为 1.6T 总参 / 49B 激活，V4-Flash 为 284B 总参 / 13B 激活，全系列默认 1M 上下文，并提供非思考 / 高思考 / 极限思考三档推理模式；Agent 编程能力达到开源 SOTA，原生适配 Claude Code 等编程智能体。V4.1 Flash（2026-09-10，552B 总参 / 8–16B 激活）补上原生多模态，把长上下文 KV Cache 再缩小约 4 倍，进一步下探多模态长文本的推理成本。DeepSeek 还确认了 V4 对国产算力（华为）的适配。

GLM 系列（2023–2025）

智谱（Zhipu AI，源自清华技术团队）走了一条与 GPT 不同的架构起点：GLM（General Language Model）采用自回归空白填充（autoregressive blank infilling）目标，试图在单一模型内统一自编码（理解）与自回归（生成）两类任务。GLM-130B（2022-08）是早期少数公开的中英双语千亿模型。

  • ChatGLM-6B（2023-03）：可消费级显卡部署的中英对话模型，是中文开源社区最早的现象级模型之一，后续迭代 ChatGLM2/3 逐步转向标准 decoder-only 路线并支持长上下文、函数调用。
  • GLM-4 系列（2024 起）：全面对齐主流能力（工具调用、代码、长上下文、多模态）。
  • GLM-4.5（2025-07，355B 总参 / 32B 激活 MoE）：把"智能、Agent、推理"三合一作为设计目标，原生强化工具使用与 Agentic 能力（多步规划、代码 Agent、浏览器操作），标志着开源模型的竞争焦点从"考试分数"转向"能否干活"。
  • GLM-5（2026-02-11，744B 总参 / 40B 激活，MIT 许可）：三项标志性突破——完全在华为昇腾芯片上训练，成为首个脱离美国 GPU 完成训练的前沿大模型；引入异步强化学习与稀疏注意力机制提升 Agent 能力；竞争重心从"写代码"升级为"写工程"（完成完整软件工程项目），在 Agent 搜索基准 BrowseComp 上超过一众闭源模型。此后节奏极快：GLM-5.1（2026-04，长时程任务）、GLM-5.2（2026-06）、GLM-5.3（2026-08 末，753B / 256 路由专家，1M 上下文，主打编码开源 SOTA）；轻量的 GLM-5.3-Flash（320B / 18B 激活，原生多模态，MIT）是 2026-10 下载量最大的大型开源模型之一。

其他值得记录的开源力量

  • Qwen（阿里通义千问）：从 Qwen-7B（2023-08）到 Qwen2.5（2024-09）形成覆盖 0.5B–72B 的完整矩阵并大规模开源；QwQ-32B（2025-03）是社区较早公开的推理模型；Qwen3（2025-04）引入混合思考模式（同一模型可开关思考链）；Qwen3.5（2026-02-16，397B 总参 / 17B 激活，Apache 2.0）把开源模型在编码与数学基准上推到与闭源旗舰正面对抗的位置；2026 年下半年迭代到 Qwen3.8 家族——Max 开放版达 2.4T 总参 / 95B 激活，27B 稠密版单卡 24GB 可跑，Flash-Next（125B 总参 / 6B 激活，额外搭配 51B 的 N-gram Embedding）展示了极致效率路线。Qwen 系是全球开源生态中衍生模型最多的家族（超过 11 万个衍生模型）。
  • MiMo（小米，2025-04）：7B 级推理模型，亮点在于"小而精"——用高质量的预训练与 RL 数据管线，从零训练即达到接近更大模型的数学/代码推理水平，验证了数据质量与 RL 流程对小模型的杠杆作用。
  • Kimi（月之暗面）：K2（2025-07-11，1T 总参 / 32B 激活）采用 MuonClip 优化器（Muon + QK-Clip 稳定注意力 logits），15.5T token 训练全程零不稳定，并把训练重心放在 Agent 数据合成与工具调用能力上；K2 Thinking（2025-11-06）践行"模型即 Agent"理念，原生掌握"边思考、边使用工具"，无需人工干预可持续 300 轮工具调用，在 Humanity's Last Exam（44.9%）与 BrowseComp（60.2%）上达到当时 SOTA，被外媒称为"又一个 DeepSeek 时刻"；K2.5（2026-01-27）引入原生视觉与Agent 集群机制（动态调度最多 100 个子 Agent、并行 1500 步）；K2.6（2026-04-20）扩展到 300 个子 Agent、4000 步长程任务；K3（2026-07-17，2.8T 总参 / 104B 激活，896 专家）成为全球最大的开源模型（首个 3T 级），底层采用自研 KDA 混合线性注意力与 Gated MLA，原生支持视觉理解与 1M 上下文。
  • MiniMax：M3（2026-06 开源，428B MoE）以自研稀疏注意力 MSA 同时做到"前沿编码 + 1M 上下文 + 原生多模态"，是国内首个三项全能的开源模型。
  • LongCat-2.0（美团，2026-07）：1.6T 总参 / 约 48B 激活，专为 Agentic Coding 设计，是业界首个在五万卡国产算力集群上完成训练部署的万亿参数开源模型。
  • 小模型路线：Microsoft Phi 系列（Phi-2/3，2023–2024）用"教科书级"合成数据证明小模型可以靠数据质量逼近大模型；Google Gemma（2024-02 起）提供了与 Gemini 同源的开源小模型。
  • 西方阵营的变化：OpenAI 于 2025-08 发布 gpt-oss-120b/20b（Apache 2.0），是自 GPT-2 以来首批开放权重模型；Meta 的 Llama 4（2025-04，Scout/Maverick MoE）之后相对地位下滑，2026-10 转向 Muse 家族（Muse Spark Open，816B / 42B 激活，全模态）；Mistral Large 4（2026-10，1T MoE / 49B 激活）延续欧洲 Apache 阵营的路线。

技术主线小结

把时间线压缩后，大模型的关键技术可以归为六条主线：

技术主线代表工作解决的问题
架构基础Transformer（2017）、RoPE、RMSNorm、SwiGLU、GQA可并行的序列建模骨架与位置编码、推理效率
规模与数据Scaling Laws（2020）、Chinchilla（2022）、Phi 数据合成算力预算下的参数/数据最优配比、小模型数据质量
对齐与推理InstructGPT/RLHF（2022）、GRPO（2024）、R1 纯 RL 推理（2025）、异步 RL（GLM-5）可用性、安全对齐、长链推理能力的涌现与蒸馏
稀疏与效率DeepSeekMoE、MLA、MTP、FP8 训练、DSA/MSA/KDA、CSA+HCA、mHC、Muon 优化器在有限算力下把参数"存得起、算得动、推得快"，1M 上下文成为默认
开源与部署LLaMA（2023）、llama.cpp/GGUF、Ollama（2023）、LoRA、KTransformers权重开放、量化压缩、个人设备本地运行与低成本微调
Agentic 与算力自主K2 Thinking"模型即 Agent"、Agent 集群（K2.5/K2.6）、GLM-5 工程化、LongCat-2.0、昇腾全栈训练模型原生具备多步工具使用与多智能体编排；摆脱对特定算力供应链的依赖

与 Agent 框架的交汇

2024 年之后，大模型与 Agent 框架的边界越来越模糊：LangChain、LlamaIndex、AutoGen、OpenAI Function Calling 等框架依赖模型的原生工具调用（Function Calling / Tool Use）能力；反过来，GLM-4.5、Kimi K2、DeepSeek-V3.1 等开源模型把 Agentic 数据直接纳入预训练与 RL 目标，"模型即 Agent 的核心引擎"成为共识。到 2026 年这个趋势走得更远：Kimi K2 Thinking 把"边思考、边使用工具"做进模型原生能力，数百步工具调用无需外部编排；K2.5/K2.6 的 Agent 集群把多智能体调度（拆解、并行、验收）内化到模型侧，框架层只剩薄薄的接入层；DeepSeek-V4 与 GLM-5 则直接以 Claude Code 等编程智能体为第一适配对象。对 Agent 框架而言，开源模型的工具调用可靠性、长上下文管理和代码能力，直接决定了框架的上限——这也是两个主题合并整理的原因。
