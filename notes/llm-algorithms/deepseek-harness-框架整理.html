DeepSeek Harness（dsh）框架整理

DeepSeek 于 2026 年 8 月开源的智能体 Harness（dsh）：把"让模型真正干活"的运行时也开源了。一切皆插件的 Cordis 架构、全量可追溯的会话模型、四种运行模式与插件生态。

定位：什么是 Harness

大模型只会"提出下一步"，而 Harness 是让模型真正干活的那个运行时——读你的仓库、执行命令、跟踪会话、展示每一步改动。官方用一条公式概括：Agent = 模型 + Harness。模型是智能体的灵魂，Harness 是智能体的身体。

DeepSeek Harness（命令别名 dsh）是 DeepSeek 于 2026 年 8 月 13 日以 developer preview 形式开源的官方智能体框架，MIT 许可，主要语言 TypeScript。一句话定位：DeepSeek 版的 Claude Code——但和"成品车"Claude Code 不同，dsh 给的是底盘加一堆可换零件：模型适配器、工具注册表、甚至"智能体怎么一步步干活"的循环逻辑本身，都是可拔插的插件。开源 12 小时即获 5000 Star，两个月内成为 GitHub 上增长最快的智能体项目之一，npm 包 @deepseek-ai/dsh 迭代极快（截至 2026 年 10 月末，npm 默认版 0.2.1-rc.2，仓库已推进到 0.2.2-alpha 系，均为预发布）。

官方圈定的五类用武之地：文档 / 数据 / 幻灯片等日常处理；编码（探索仓库、修 bug、写功能、跑测试）；带引用来源的调研；后台任务与批处理脚本；安装或开发插件。

架构核心：一切皆插件

dsh 构建在 Cordis 插件系统之上（DeepSeek 2022 年开源的项目），架构口号是 "Everything is a Plugin"，设计思想见论文《A Programming Paradigm for Spatiotemporal Composability》。Cordis 内核极简，只做三件事：加载插件、卸载插件、解析依赖。其余一切能力都是插件——模型连接器、工具定义、技能库、沙箱、记忆存储、UI 层，甚至智能体的主循环逻辑，改配置文件就能换，不用动源码。

Cordis 有两个关键性质，也是论文标题里"时空可组合"的含义：

  • 时间可组合（temporal composability）：插件卸载时，它产生的副作用可以完整回滚，系统状态回到卸载前。
  • 空间可组合（spatial composability）：插件配置变更后，插件间的依赖关系会动态重建，不需要重启整个系统。

仓库采用 pnpm monorepo 组织：packages/ 是核心 npm 包（含 Cordis 集成与官方 bundle 清单 @deepseek-ai/dsh-official-bundles），apps/ 是 Web UI（官方把 Web UI 作为主要上手路径），另有 Python SDK、native/ 原生层、docs/（ADR 架构决策记录、cookbook）与 benchmarks/。工程规范相当严格：ADR 流程、Oxlint/lefthook/jscpd 检查，文档全部中英双语成对维护。插件与运行时的接入点用 slot / inject（槽位注入）机制描述，LLM 适配层则有 "twin LLM adapters"、"capability seams" 等 ADR 设计。

全量可追溯与会话模型

dsh 把模型看到的每一字节都记录在 append-only 的会话日志里：系统提示、推理过程、工具调用与结果、子智能体调度、每一次上下文注入。基于同一条事件流提供：

  • Trajectory 视图：按来源审查记录，适合合规审计、代码评审、带新人等需要"看清楚智能体干了什么"的场景。
  • resume / fork / 搜索 / 重放：长任务出问题时回退重试，而不是推倒重来。

会话的两个核心概念：

  • turn：你交给它的一个完整任务。
  • step：它干的一次活——请求一次模型 + 调用一批工具。

人工审批与工具拦截都是挂在 step 前后的钩子：要不要人工批准才能执行？删文件、联网前拦一道？都是配置项，不是改代码。

四种运行模式

四种模式本质上是四组预先配好的插件组合：

模式定位说明
标准通用日常文档、数据、调研等均衡配置
代码编码任务强化仓库探索、修改、测试相关工具链
极简基准与轻量官方跑 DeepSeek-V4-Pro 成绩时使用的档位
创造插件创作Creator mode：通过对话让 dsh 自己写插件、装进运行时

想确认当前 profile 实际加载了哪些插件：dsh --profile web --dump-config。

安装与模型配置

  • 桌面安装包（最省事）：官网 deepseek.com/harness 下载，目前覆盖 macOS（Apple 芯片）与 Windows x64，无需 Node.js。
  • npx 一行启动（推荐开发者）：npx @deepseek-ai/dsh web，前置 Node.js 22.19+ 或 24 LTS，浏览器打开 127.0.0.1:3080。
  • 源码构建（插件作者）：pnpm install && pnpm run build && pnpm dsh web。

模型配置在 Web UI 的 Settings → Models 填 API Key（默认端点 api.deepseek.com），凭证存于 $DSH_HOME/.credentials.yaml；同时支持 Anthropic 与 OpenAI 兼容协议的自定义端点——接哪家模型都行。

官方推荐的高性价比组合是 dsh + DeepSeek-V4.1-Flash：长时程 Agent 任务大量消耗输入 token（反复读仓库），V4.1-Flash 的 KV Cache 压缩与低定价正好把这块成本打到很低——"开源身体配开源大脑"。注意官方推理价格分峰谷时段，高峰输出 token 单价最高可达低谷的约 4.55 倍，大批量任务前先看时段。

插件生态与开发

  • 找插件：在 GitHub 用 dsh-plugin 标签检索社区插件（如 dsh-at-file、dsh-genui），通过 plugin manager 安装 bundle。
  • 写插件：Creator mode 下直接用自然语言让 dsh 写一个插件并挂进运行时。官方示例（写一个悬浮番茄钟）：加载 cordis-plugin-development 技能 → 检查 providers 与 runtimeSlots → 生成 dsh-plugin-*/package.json 与 client.js → 调用 plugin_manager 的 install_bundle → 起一个 shell 验证插件状态。全程约 5 分钟，这正是 dsh 与成品类工具最大的差异点：它想让你改造它。
  • 插件权限：插件可以读文件系统、完整会话历史和工作流控制——装第三方插件前先审代码，生产环境要有沙箱隔离。

使用提醒

  • 仍是 developer preview：官方明确接口可能有破坏性变更，别把生产工作流绑死在某个预览版上，留好回滚方案。
  • 隔离运行：它会执行模型生成的命令，官方要求在隔离环境中运行，并对可访问文件做好备份。
  • 平台覆盖：桌面安装包目前只有 macOS Apple 芯片与 Win x64；Linux / Intel Mac 走 npx web 模式。

在开源 Agent 版图中的位置

dsh 是"开源模型阵营补齐 Harness 层"的标志性事件：DeepSeek 此前开源了模型权重（V3/V4 系列）与推理效率技术（MLA/DSA），dsh 补上了模型之外让能力落地的执行层，与 Claude Code（闭源成品）、OpenAI Codex CLI 等形成对照。它延续了综述笔记里"Agent 能力内化到模型侧"的趋势——官方演示中 dsh 与 V4-Pro 的组合在 agentic coding 基准上达到开源 SOTA，模型与 Harness 由同一家打造、协同优化，这条"模型 + Harness 双开源"路线值得关注。
